# Tarea 1 Sistema de Cuentas Bancarias

Proyecto para el ramo Base de datos II en la Universidad de Magallanes

El programa limpia datos de cuentas de banco y hace depositos giros y transferencias usando programacion orientada a objetos en python

## Estructura

* src/proyecto_banco/main.py: aca esta la funcion que limpia datos las clases y las pruebas
* DECLARACION_IA.md: declaracion sobre el uso de ia
* pyproject.toml: archivo del proyecto con uv

## Como ejecutar

uv run python src/proyecto_banco/main.py

o tambien

python src/proyecto_banco/main.py
